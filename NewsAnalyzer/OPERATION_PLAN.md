# NewsAnalyzer 운영 계획서

## 🎯 서비스 개요

**NewsAnalyzer**는 정치인 관련 뉴스를 자동 수집하고 LDA(Latent Dirichlet Allocation) 토픽 분석을 수행하여 InsightForge에 실시간으로 반영하는 독립 서비스입니다.

## 📅 운영 스케줄

### 일일 작업 (자동)
- **06:00** - 뉴스 수집
  - 네이버 API 호출 (496명 × 100개 = 49,600개 기사)
  - 소요 시간: 약 2-3시간
  - 저장: `data/collected/news_collected_YYYYMMDD.json`

- **07:00** - LDA 분석
  - 형태소 분석 (KoNLPy Okt)
  - 토픽 모델링 (Gensim LDA)
  - 소요 시간: 약 1-2시간
  - 저장: `output/lda_results/assembly_lda_YYYYMMDD.json`

- **08:00** - InsightForge 업데이트
  - LDA 결과 복사
  - Git 커밋 및 푸시
  - Vercel 자동 배포
  - 소요 시간: 약 5-10분

### 주간 작업 (수동)
- **매주 월요일** - 로그 점검
- **매주 수요일** - 데이터 백업
- **매주 금요일** - 성능 모니터링

## 💾 데이터 관리

### 보관 기간
- **수집 데이터**: 30일 (자동 삭제)
- **LDA 결과**: 90일 (분석용)
- **로그 파일**: 7일 (자동 순환)

### 백업
- **자동 백업**: 시놀로지 Hyper Backup (매일 자정)
- **수동 백업**: 주간 단위로 중요 결과 별도 저장

## 🔧 기술 스택

### 뉴스 수집
- **API**: 네이버 뉴스 검색 API
- **라이브러리**: requests, beautifulsoup4
- **속도**: 100ms/request (API 제한 준수)

### LDA 분석
- **형태소 분석**: KoNLPy Okt (한국어 최적화)
- **토픽 모델링**: Gensim LDA
- **파라미터**:
  - 토픽 수: 5개
  - Passes: 10
  - Iterations: 100
  - 상위 키워드: 20개

### 자동화
- **스케줄러**: Python schedule
- **컨테이너**: Docker + Docker Compose
- **재시작**: unless-stopped (자동 복구)
